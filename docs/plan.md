# План первой версии

Каждый этап заканчивается работающим приложением, которое можно запустить.

1. ✅ **Каркас и манифесты.** Решение, проекты Core/App/Tests; модель манифеста, загрузка и валидация; настройки с корнями скриптов; дерево скриптов и просмотр скрипта.
2. ✅ **Форма параметров.** Контролы для всех типов, `required`, `default` с выражениями дат, проверка перед запуском, личные пресеты.
3. ✅ **Подключения.** Окна MS SQL и PostgreSQL, список БД с сервера, недавние подключения, пароли в Credential Manager.
4. ✅ **T-SQL runner и результаты.** Параметры, `GO`, лог `PRINT` в реальном времени, таблицы результатов, остановка, копирование и экспорт в CSV.
5. ✅ **Перенос скриптов из Red Gate.** Скрипты из db-scripts перенесены в `samples` (разовым импортом, в программе его нет), даты и необязательные параметры доработаны.
6. ✅ **PL/pgSQL, PowerShell, Python runners.** `set_config` для `DO`, процессы с переменными окружения, `RESULT_DIR`. Переписать Export Binary Data и Decode Kafka Message.
7. ✅ **Git.** _(код и тесты на временных репозиториях готовы, в приложении ещё не проверено)_ fetch/pull, статус скриптов, публикация (commit + push), копирование между корнями.
8. ✅ **Добавление и правка скриптов.** Окно импорта из файла или вставкой, поиск параметров в T-SQL, PL/pgSQL, PowerShell, Python, правка параметров и подключений, запись манифеста.
9. ✅ **Манифесты и пресеты в `.manifests` и `.presets`.** Папки скриптов без служебных файлов, все пресеты — в файле пресетов скрипта (личные из `%APPDATA%` перенесены), публикация пресетов по одному.
